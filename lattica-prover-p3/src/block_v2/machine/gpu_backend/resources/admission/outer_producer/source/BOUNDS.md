# Source outer phase envelope

The source envelope is a prerequisite for a closed native-to-outer owner. It
does not reserve storage, create a proof, register a program, or authenticate a
transaction. Its separate move-only backend preissue fixes the idle execution
selection before native work; binding a genuine compiled source consumes that
same plan without new memory admission or planning. Enclosing original claims
remain mandatory. The unchanged genuine-Program outer planner remains the
default admission path. Full-transaction PairedV1 remains disabled.

The enclosing owner must supply the source-derived operation classes, wire
bound, exact witness count, and SelectHint logical payload count from the
original request-bound group source plan. Numeric inputs alone carry no request
identity. The SHAKE compiler profile has 46 public values and the existing
2 GiB requested construction limit, at most 2^20 witness values, and at most
2^20 padded rows, with the unchanged wide AIR and cryptographic profile.

The GPU metadata ceiling uses the actual pinned layout constants:

- 24 header words, 18 words per operation, all SelectHint words;
- four words per active row and seven words per port;
- one port per scalar operation, three per cubic operation, eight per Poseidon;
- the exact selected public width, without adding metadata rows for trace padding;
- eight bytes per word, the compiler's wires/four-operation-word scratch and
  its 1024-byte fixed addition, plus the actual WitnessSchedule storage bound.

Retained source uses the full construction quota plus the exact Arc allocation
layout. Actual spare/nested capacities and construction history are checked
against that ceiling. Input backing preserves the compiler's existing 2^20
value-capacity limit and the separate two-times-public allowance. It does not
shrink original compiler reservations to observed capacities.

Every power-of-two row count from eight through the source upper bound is
screened before native execution. Each row uses the same source metadata ceiling
and captured immutable execution/tree selection. The shared complete precommit,
opening, randomness, witness and independent-verifier planners provide all
per-row feasibility checks. The report takes componentwise maxima for output
and verifier owners; it never assumes a measured largest row also maximizes an
adaptive workspace. The managed phase ceiling is the entire existing 8 GiB,
including startup backing, with the existing 4 GiB context reserve. Host scope
is the supplied real native assignment, capped by the existing 24 GiB limit,
plus the existing 8 GiB tree quota inside the 32 GiB worker limit.

The additional metadata declaration counts the new inline envelope, row plans,
and moved/result/report slots. The caller must separately keep the existing
planner scratch reservation alive. No vector of plans or synthetic Program is
allocated, and no invalid hint/template is evaluated here.

After genuine compilation, conformance checks compare every operation class,
hint word, row count, wire/input count, source capacity, actual GPU Layout and
captured-profile Bounds. Per-row output/key/verifier values must fit the original
componentwise envelope. A mismatch is a refusal before outer dispatch, never a
new admission, fallback or retry.

The test-only research continuation provides original request-bound enclosing
metadata/output/report claims and sealed native/startup phase continuity for a
singleton component. The copyable report has no conversion to authority.
Backend preissue cannot authorize native or transaction dispatch. This is not

## Complete graph and aggregate widths

`registered_graph_bounds` accepts exactly 28 public values for a complete graph
and 25 for an ordered aggregate. It uses the same 2 GiB construction, 2^20
witness and row ceilings, wire ceiling, AIR and cryptographic profile. Existing
SHAKE constructors still select 46. The selected width is a private field and
participates in row packing, GPU layout, input backing, every backend row plan,
output and verifier storage, and genuine compiler/public-vector conformance.
Cross-profile public widths are rejected before dispatch.

These constructors produce numerical source facts only. Source identity,
original reservations, complete graph coverage, independent verifier scratch
and retained child provenance remain duties of the enclosing workflow. The
source-bounded aggregate compiler routes both graph and batch children through
the maintained bounded symbolic verifier; the default compiler is unchanged.
