# Fixed native SHAKE continuation

This release Linux/x86_64 research boundary accepts only an opaque recording,
the exact request input, and borrowed original runtime/preparation/verifier
claims. It accepts no AIR callback, generator, proof, key or caller entropy.
The closed research caller establishes that the recording is the actual lane
AIR, keeps the exact request immutable, owns process serialization and guarded
preflight, and must independently verify the result after runtime retirement.
The unsafe lifecycle methods document those obligations explicitly; numeric
receipts or same-sized unrelated reservations do not establish provenance.

Admission checks the unchanged 32 GiB worker, 8 GiB managed GPU and 4 GiB
context limits. The original preparation token owns A016's symbolic, periodic,
configuration and planner partitions plus A021's bridge headers. The original
verifier token must own exactly 64 MiB before any configuration or trace work.
The consumed output claim already owns its original 64 MiB NativeProof and
fixed Report reservations. Raw request and research owner storage remain the
closed caller's responsibility.

Before inspecting the physical execution plan, the phase reserves the B032
OpenCL wrapper inventory plus overlapping phase headers. It derives the PCS
host allowance from the actual remaining original ledger, capped at 24 GiB.
B038's device-tree opening model retains all original/future trees and hash
workspace without early-release credit. The phase reserves the complete 8 GiB
managed ceiling minus the exact original startup baseline, rather than using a
measured peak as an allowance. The default constructor refuses host-tree plans;
the separate explicit host constructor is documented in [HOST_PROFILE.md](HOST_PROFILE.md).
Both constructors refuse incomplete plans. These
PCS/OpenCL claims remain in NativeShakePhase until the caller has retired the
exact runtime, including every error path after startup.

Production marks the phase attempted before any validation. B034 binds the
actual capacity lease, selected device, runtime epoch, original claims and
fresh proof session. Configuration is attempted exactly once with three fresh
32-byte SysRng draws and the owned-seed constructor; this path does not use a
thread-local RNG or caller seeds. Fixed metadata normalization rejects invalid
degrees/programs before private trace generation. The only generators are the
existing singleton/batch lane kernels under GpuRequired. Native segmentation,
the degree-seven/sixteen-chunk hiding profile, transcript and PCS are unchanged.

The public transfer must be exactly 216 canonical field words. The proof and
actual completed stage report are audited by B037 before an opaque output can
leave the phase. Temporary configuration/session/capacity owners are destroyed
first. The result retains the original output/report claims and exposes only
borrows. This method does not attach graph children, run CPU verification,
enable a production dispatch, authorize retries or qualify a speedup.

Five CPU tests cover one-shot refusal, allocation-free original-claim checks,
missing verifier refusal before environment selection, category/limit changes,
and canonical fixed-size public handoff. They are authored but not executed by
this capsule. Guarded configuration allocation, exact runtime/session failure
cleanup, fresh singleton proof production, independent CPU verification and
mutation checks remain separate coordinator-run qualification steps.
