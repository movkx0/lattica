Combine polynomial openings before expansion

November 11, 2026 · enabled by default · checkpoint 1212133

The GPU now combines compatible single-point polynomial openings before their full-domain transforms and rational reductions. Every original column weight and claimed-value observation is preserved. Quotient evaluation also reuses one immutable interpolation per input across output cosets.

For a shared point z, the change uses the exact identity sum a_i*(p_i(x)-p_i(z))/(x-z) = (sum a_i*p_i(x)-sum a_i*p_i(z))/(x-z). Compression preserves the original matrix and column alpha exponents. The measured workload reduces 88 separate expansions and reductions to 13 groups per proof.
