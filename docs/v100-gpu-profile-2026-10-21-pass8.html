Selected code change

The width-eight Poseidon matrix reducer now consumes reconstruction and modular-fold carries directly with PTX add.cc and addc. This removes compiler-generated carry comparisons in the bounded reduction. The existing NVIDIA V100 capability-7.0 gate selects the sequence. The portable preprocessed code is identical to the baseline. NTT code and scheduling, memory admission, proof parameters, randomness and verifiers are unchanged.

Let B = 2³² and p = B² − B + 1. For 0 ≤ low, high ≤ 21(B − 1), the reconstructed value S = low + high·B is at most 21(B² − 1). Its high 64-bit word is therefore at most 20. Folding this word uses B² ≡ B − 1 modulo p. If that addition carries, adding B − 1 again produces at most 21(B − 1) − 1, which cannot overflow 64 bits. Both external and fixed internal matrix callers already satisfy the limb bound.

Measurement boundaries and limitations

  • Four-input aggregation: Aggregation call plus GPU drain; excludes context initialization, artifact output and CPU audit.
  • Eight-input aggregation: Cohort launch to worker exit; includes initialization, start barrier, aggregation, artifact output and shutdown; excludes CPU audit.
  • Two concurrent eight-input jobs: Cohort launch to last of two worker exits; includes both initializations, start barrier, aggregations, artifact output and shutdown; excludes CPU audits.
  • Native JoinSplit: Native ABI proving call plus GPU drain; excludes context initialization, buffer setup, artifact output and CPU audit.
  • One Tesla V100-PCIE-32GB, fixed aggregation fixtures and bounded resource settings.
  • Three four-input pairs, two eight-input pairs, two concurrent pairs and twelve native pairs; limited sample counts.
  • Warmed alternating pairs. First-use profiles and warmups are retained but excluded from the qualification medians.
  • Both pooled medians and within-pair reductions are reported; short native calls remain sensitive to timing variation.
  • Kernel event totals and inclusive host spans are not additive; gaps in event coverage do not establish GPU idle time.
  • No cold-cache, Apple GPU, full-block or production qualification in this run.

First source-use JIT profiles and warmups are retained separately and excluded from qualification medians. Builds and other GPU work did not overlap proof timing.

Primary technical references

  • NVIDIA CUDA C++ Best Practices Guide — Use shared memory for reused data, measure shared-memory and synchronization tradeoffs, and verify complete application performance. Compact and expanded NTT tables are local hypotheses, not vendor performance claims.
  • NVIDIA Volta Tuning Guide — Keep explicit workgroup synchronization between threads sharing data. Volta independent thread scheduling does not justify assuming implicit warp synchronization. Existing launch and memory admission remain enforced.
  • NVIDIA PTX ISA 8.5: extended-precision integer arithmetic — add.cc records carry and addc consumes it. The bounded two-fold Goldilocks sequence and its proof are locally derived; only existing V100-gated code uses the new sequence.
