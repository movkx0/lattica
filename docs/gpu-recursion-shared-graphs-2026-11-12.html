Implementation

Matching graph positions share one GPU preprocessing cache. Parent compilation and template lowering now use the weighted CPU preparation window, allowing the next parent to prepare while the GPU proves its predecessor. Each child proof moves into one admitted job and is dropped before lowering. Exact template identity and independent graph verification remain mandatory.

The retained-input and graph-proof allowance remains 2 GiB. The measured peak was 62.1 MiB for this archived-input comparison, which has no retained request or branch inputs. This is not an estimate of full-transaction memory.
