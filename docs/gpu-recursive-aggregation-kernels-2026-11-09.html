Wider groups

Wider-group probes use r34; final kernel screens, correctness checks and matched proof measurements use r35. The intervening changes improve failure detail and memory sampling. The new diagnostics identify the first rejected resource. Graph width eight first exceeded the 1,048,576 input-value limit (requested 1,048,691). Raising inputs to 2,097,152 exposed a 2,284,340,592-byte construction request against 2,147,483,648 bytes. The 3 GiB compiler / two-live-job / 16 GiB tree policy passed construction but required 8,749,958,456 witness bytes against 8,586,788,864 remaining backend bytes.

SHAKE width eight required 13,449,683,528 managed GPU bytes (12.526 GiB) even for the minimum complete transform, above the 12 GiB maximum. With the expanded tree reservation, width four also lacked opening workspace; preflight split to width two. Standard and input-only policies retained width four. These were proof-free checks with explicit session cleanup. No allocation cap or geometry qualification was bypassed. The enclosing research envelope remains 36 GiB and the backend envelope remains 32 GiB.

Validation and use

22 core tests, 16 research tests, 60 Python tests and three GPU oracle tests passed. CPU-only and legacy GPU compatibility checks passed. All 112 recursive proofs in final qualification and matched screens verified, and all sessions closed. These Linux checks do not qualify macOS. New options are restricted to the research experiment; existing defaults remain available.

Use the guarded aggregation runner with --profile grouped-v5 --pipeline lookahead --identity cpu --ntt-profile smalltile. NTT alternatives are baseline|powers|split8|smalltile|padded|local48; Poseidon alternatives are baseline|square|square-unroll. preflight-groups compiles and admits without proving; kernel-screen uses public deterministic data. Expanded policies wide-inputs|wide-memory require N4. Memory qualifications bind source, executable, GPU, driver, geometry, gather mode and complete kernel/compiler policy; regenerate them after source or binary changes.

All hardware jobs were serialized under the existing exclusive guard. Builds were excluded from the persistent ledger; failed attempts remain charged. Remaining test budget: 1349.8 of 12600 cumulative authorized seconds. The initial kernel screen finished before the old two-second memory sampler observed it; a kernel-screen-only 100 ms sampling interval fixed this without adding idle time to the workload. Early final-qualification attempts rejected unsupported baseline CLI flags and an older-source input bundle; fresh bound inputs were generated before final measurements.
