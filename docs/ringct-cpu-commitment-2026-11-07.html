Implementation

Checkpoint-aligned replay carries private RNG state across four 256-row tiles, avoiding repeated prefix replay. Packed and salt buffers live in bounded shards and retire with the commitment. The packed path transposes four rows with the existing field interleave operations; scalar and partial tails retain the portable fallback. The chunked path additionally processes 256 Merkle parent rows per parallel item. Each path preserves permutation constants, salt order and rejection sampling, transcript, caps and proof encoding.

The explicit --cpu-commitment-path existing|replay|packed|chunked selector is per context. The three new paths are cumulative and require the combined memory variant and existing hash kernel. Normal defaults are unchanged. Both comparison arms use the latest combined/existing-hash configuration with identity overlap enabled, including --baseline-identity-overlap 1; no gain from the previous identity optimization is counted again.

These are exploratory single-sample screens, not precise estimates of sustained regressions. No path met the promotion gate. On the existing path at height 2²¹ and sixteen threads, hashing accounted for 94.5–99.1% of measured leaf-worker time. Replay accounted for 0.2–4.8% and packing about 0.7%. The replay path reduced regenerated salt rows by 60% and buffer sets from 8,192 to 16, but did not produce a qualifying total-time improvement. This points toward hash arithmetic as the remaining major cost.
