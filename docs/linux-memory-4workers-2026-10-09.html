It used the identical prover binary, 6.25 GiB managed VRAM per worker, 512 MiB reserved driver context per worker, and heavy=1, late=1, query=1 permits.

Memory and concurrency

Sampled fleet RAM peaked at 30.83 GiB under an enforced 36 GiB cap. The conservative model requires 44.5 GiB. This was an explicitly capped experiment below that bound, with the normal OS reserve, per-worker bounds, tmpfs checks and swap prohibition retained. There were zero worker or fleet memory-limit events. At most 2 workers simultaneously held heavy or late phase permits.

Each worker spent between 344 and 467 seconds waiting for the heavy-phase permit. The RAM cap was not reached; four worker processes do not imply four simultaneously admitted memory-heavy proving phases.

Both GPUs had admitted proving phases overlapping for 286.05 seconds. Same-GPU overlap is recorded per device in the evidence file. Per-worker memory peaks are charged cgroup peaks and must not be summed as a simultaneous physical-memory peak.
