Implemented changes

  • Immutable typed lowering of extension opening reductions, four terms per transition row.
  • Two Poseidon operations per row, bounded arithmetic/hash table partitions and trusted geometry.
  • Direct native batches up to 16; omit a parent when one batch covers the complete request.
  • Compact trusted child verifier keys release source programs and GPU preprocessing before parent compilation.
  • Bounded public preprocessing prefix and fixed-salt host backing with context validation and explicit transfer accounting.
  • Sequential GPU quotient scratch; trace commitments release unique input/hiding storage table by table and quotient commitments release masks after each group’s final chunk.
  • Lazy prefix allocation with stable mixed-height ordering and conservative accounting for shared aliases.

Measurement scope

  • Samples revalidate deterministic archived native proofs; they do not generate fresh RingCT transactions.
  • Complete request samples include native import/revalidation/compilation, public setup, CPU witness, upload, GPU proving and CPU verification; process startup is excluded.
  • The original scalar program is still retained as the CPU witness oracle; this is not a complete direct typed verifier frontend.
  • CPU identity hashing and the pinned Goldilocks/FRI security parameters are preserved.
  • No complete 109-component request or fresh N3/N4 workflow is claimed.

Remaining work after the gates

  • Direct typed transcript/Merkle/FRI frontend and independently bounded verifier witnesses.
  • Global dependency scheduling across requests with weighted admission for up to 16 CPU preparation workers.
  • AggregatePlan/GpuMemoryPlan integration and bounded AggregateArtifactV2 export/verification with v1 compatibility.
  • Complete 109-component and fresh N3/N4 qualification before production promotion.
