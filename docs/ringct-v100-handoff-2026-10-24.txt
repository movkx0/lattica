Historical RTX 5080 baseline

Seven fresh N3/N4 transactions took 40067.428264729 seconds, or approximately
0.62894 transactions/hour, including the complete correctness workflow. Counts
were 1,554 native, 3,115 recursive transaction and five final batch proofs.
This is a single historical baseline, not V100 throughput or a candidate win.
The older 0.66 transactions/hour observation is not the selected baseline.

Keep FreshOnly proof generation and GpuRequired execution for faithful RingCT
candidates. Report public preprocessing reuse separately. Preserve the resource
contract for matched comparisons:
  8 GiB managed GPU memory, 4 GiB GPU context reserve;
  32 GiB worker host allowance, 24 GiB native allowance;
  47 GiB process cgroup cap, zero swap;
  1,048,576 maximum rows, unchanged thread/security parameters.
The V100's 32GB capacity does not automatically enlarge these allowances.

Preparing the new machine

Fetch and check out ringct/v100-handoff-20261024 from the repository remote.
Rebuild from source; this snapshot deliberately omits caches and executables.
The recorded Linux toolchain is Rust/Cargo 1.96.0. Install the required native
dependencies and NVIDIA driver/OpenCL ICD, then populate the locked Cargo
dependencies for research/pq-ringct-batch and research/pq-direct-spend.

The current guard scripts hardcode /home/access and the toolchain path
/home/access/code/lattica/.tools/rust-1.96.0/bin. Adapt these paths to the new
machine in research/pq-ringct/tools/opencl_private_spend_validate.py (and the
historical opencl_opt_validate.py where needed). They also use repository-local
.tools/cargo-opencl and .tools/target-opencl. Do not copy the old absolute
worktree/cache symlinks. The offline build requires dependencies already cached.

The guard requires systemd user services and delegated cgroup memory controls.
Check zero-swap enforcement, process admission, and the actual V100 device
selection before executing jobs; GPU device index 0 is currently selected.
Keep the guard limits and use one shared flock lock across all development
worktrees. Parallel source development is allowed; builds and GPU runs remain
serialized. Build profile is cpu-required, full workflow is gpu-required.

After path setup, begin with a guarded release build of:
  cargo build --locked --offline --release \
    --manifest-path research/pq-ringct-batch/Cargo.toml \
    --features opencl --bin pq-ringct-opencl-opt-validate
Then rerun focused checks and qualify a fresh baseline on the V100. Old RTX
receipts, binaries and timings cannot qualify the new device. Before any timed
candidate comparison, complete fresh N3/N4 correctness, independent CPU
verification, mutation and artifact round-trip checks, and terminal audits.

Acceptance remains at least 5% lower median complete-workflow time for A/B with
no case median regression above 2%, using three matched alternating pairs after
