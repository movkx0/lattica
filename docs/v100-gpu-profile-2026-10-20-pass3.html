V100 GPU prover: scalar absorption and delayed sum reduction

20 October 2026 · Third optimization pass · Tesla V100-PCIE-32GB

This run starts from the previously validated shared-twiddle NTT build. The new changes keep the LDE sponge state at fixed indices and reduce the eight-word Poseidon2 internal sum once. The isolated row-hashing screen improved by 6.15–6.91% across six shapes; complete-proof results are below.

What changed

The previous absorb loop indexed s[at++]. The new loop finishes a pending block, absorbs complete four-word blocks, and retains a partial suffix using constant state indices. The compiler-reported private allocation falls from 64 bytes to zero in the measured kernel. The helper for the internal round accumulates low and high 32-bit limbs separately, reconstructs the exact 128-bit sum with one carry, and reduces once. Each accumulator is below 235, including arbitrary noncanonical u64 inputs.

The proof format, field, round constants, sponge semantics, verifier, NTT schedule, resource admission and power limit are unchanged. The implementation uses portable OpenCL arithmetic; performance evidence is specific to this V100.

Rejected experiments

  • Portable specialized squaring: inconsistent results, slower on most shapes
  • PTX specialized squaring: slower
  • Balanced addition tree: negligible benefit
  • Carry-count deferred sum: slower than limb sums
  • Aligned-only absorption: superseded by handling all offsets without dynamic state indexing
  • Explicit hash loop unrolling: no consistent added benefit

Research used

  • NVIDIA Volta Tuning Guide: Investigated dependency chains and resource tradeoffs; performance decisions use measured kernels and complete proofs.
  • NVIDIA PTX ISA: Tested explicit 32-bit wide multiplication for squaring; rejected it after measurements.
  • NVIDIA CUDA Programming Guide: local memory: Dynamically indexed arrays may reside in local memory. Fixed state indices reduced the measured OpenCL private allocation from 64 bytes to zero.

Scope and limits

  • One Tesla V100-PCIE-32GB; fixed demo/aggregation fixtures and bounded resource settings.
  • Warmed alternating pairs; first-use profiles and warmups excluded from qualification medians.
  • Five four-input pairs, three single eight-input pairs, three two-job concurrent pairs, twenty native JoinSplit pairs.
  • Kernel event totals and inclusive host spans are not additive.
  • No cold-cache, Apple GPU, full-block or production qualification in this run.
  • The dedicated NVIDIA cooperative hashing kernels and Metal implementation were not changed.
