Prepare witnesses while the GPU proves

2026-11-14 · default recursive aggregation pipeline

CPU workers now evaluate and materialize each private witness before handing its admitted job to the sole GPU owner. This moves CPU work off the GPU-owning thread and lets it overlap the preceding proof. Graph and AES/SHAKE leaves and parents use the path by default.
