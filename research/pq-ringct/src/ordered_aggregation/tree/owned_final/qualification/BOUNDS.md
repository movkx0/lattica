## Actual success and rejection semantics

The original is first verified independently against exact ordered original statements. The artifact action encodes original proof bytes, roundtrips disk, bounded-decodes, independently verifies the decoded proof against those statements, then canonical re-encodes and compares bytes. Public mutation changes the aggregate ROOT public coordinate by one. Raw proof mutation changes actual trace_local[0] by Challenge::ONE, keeping shape/caps/degrees/terminal intact. Only RegisteredVerificationFailure::RelationRejected from the numerical verify_batch path counts; Admission/Configuration/Allocation failures and unexpected success fail qualification. Both values are restored and verify_expected is rerun after each rejection. The original proof is never modified. Three positive decoded checks and two typed numerical rejections are required.

Only after all checks and local proof/buffer destruction does a fixed FinalQualificationReport carry true flags, actual packet/proof lengths, full digest, disk device/inode, source/profile/context/height and actual timing intervals. Its default flags remain false. CPU verification timing includes original+decoded+mutation/restoration checks; disk/encoding/decoding are separately recorded and included in complete workflow time. No header-only/codec-only rejection receives cryptographic mutation credit.
