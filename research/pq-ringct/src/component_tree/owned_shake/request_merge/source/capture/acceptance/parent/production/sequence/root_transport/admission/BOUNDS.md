# Private original-root transport admission prerequisite

These new files do not declare a module in the sequence, add an adapter, create
an ignored selector, change a driver, or activate an artifact operation. They
compose only with the separately reviewed B root_transport and C header files.
The coordinator owns all ancestor wiring. Cross-draft dependencies must be
frozen external payload/capsule pins, not fictitious canonical postimages.

## Authority and temporal boundary

`PreissuedRootTransport` retains the exact `ParentSourceBound` reference. Its
constructor checks the original request against the same concrete ledger,
derives the final Parent3 spec and fixed 38-field source header, computes the
18-height source transport and CPU envelopes, and admits both original claims.
All state remains private and non-Clone. Accessors expose only immutable source
metadata and numeric geometry; they grant no proof/key access or continuation.
The source header helper uses the same maintained semantics as B065 without
changing that action's visibility or behavior.

The function name and Source+Ledger do not establish temporal order. A future
reviewed driver must construct this owner before `Attempt`, `PendingNative` and
all actual proof dispatch, and retain it for the whole component attempt. No
late issuance, running-path upgrade, retry, splitting or fallback is authorized.
The driver's entry/ledger bootstrap and final error formatting require its own
original caller claim. This inactive source prerequisite supplies no such
driver, runtime phase token, physical admission certificate or dispatch right.

B's consuming same-Component action must authenticate its actual root, source,
original request, ledger, retirement, height, exact cap and public/header shape
before any codec operation. It must retain that Component's original key, proof,
runtime, support and caller through the operation and root destruction. A's
geometry report is not a substitute for those retained owners or checks.

## Complete outer-packet limits

The locally trusted registered codec remains LBV2RP02 with its unchanged 2 MiB
inner ceiling including the eight-byte inner magic. C's separate versioned
SHAKE-root outer header has exactly 2,480 bytes. Both complete outer packets
also have the same unchanged 2 MiB ceiling; the header is not extra allowance.

Before Attempt, every one of the 18 conservative source heights must satisfy:

`2480 + encoded_inner_bytes + 1 <= 2 MiB`.

The final byte reserves C's trailing-byte syntax probe inside packet2's existing
capacity. There is no third packet and no cap increase. Exact cap arithmetic,
the 18 expected heights, encoded magic/canonical relationship, cumulative
decoded backing and aggregate maxima are checked without creating a proof.
Actual encoding length checks are source-drift refusals, never a new post-proof
fit decision, retry or permission to enlarge a buffer.

A045 derives the conservative 54-column schema from the pinned maintained
packing rules; A046 validates that synthetic schema against the actual codec.
Neither validates an actual root's fit. Later actual-original positive codec
and numerical checks remain necessary and must preserve this distinction.

## All-live original ownership

The first original reservation covers all complete fixed source/header/envelope,
codec, B adapter, C probe, result/error, report and destruction frames. It is
admitted before the source check, envelope arrays or source-header construction.
The second original reservation covers, additively:

- the full 64 MiB cumulative decoder allowance, including all nested vector
  backing and the decoder's additional canonical re-encoding allocation;
- two full 2 MiB packet capacities, including every unused byte;
- the all-18-height independent CPU verifier lifecycle and the separate typed
  classified-call increment, with no credit for its internally assumed input.

The original retained proof/key/runtime remain live under their separate source
and Component-owned claims. They are never replaced by the decoded proof or
subtracted from these new claims. Ledger admission must fit the complete active
source/attempt/native/storage set inside unchanged worker allowances. A numeric
incremental report alone cannot certify that combined peak or the 47 GiB process
cap, zero swap, 8 GiB managed GPU and 4 GiB context reserve.

The decoded proof may coexist with the original, both complete packets, the
source header/public/cap views, core canonical scratch and the independent
verifier. B destroys the decoded proof before C's framing probes, but the entire
64 MiB cumulative quota remains reserved. C reuses packet2 after exact canonical
equality and never changes the original proof or packet1. Both packets and the
actual root die before the final borrowed diagnostic report is returned.

`PreissuedRootTransport` declares its fixed state first and its payload/fixed
reservations last. It has no split, release, Clone, extraction or conversion API.
B's non-Copy/non-Clone report owner retains this entire owner, declares the report
before the owner and permits only a checked report borrow. Returned failures
destroy codec/probe payloads while those original claims and the Component's
existing caller remain live; the future driver's caller backs the returned fixed
error after the private phase ends. Rust unwind destruction does not by itself
qualify asynchronous or physical engine/device teardown.

## Fixed forwarding census

`codec_frames` repeats A046's concrete source-traced bound: every complete
registered schema value and Result is added at every level, plus the pinned
Storage/Attempt/Guard/Visit/Seed/Access, Postcard Slice, fixed-u64, serde visitor
and iteration controls. All 32 permitted compound levels and 16 additive
forwarding frames per level are charged. No inlining, union, stack-slot reuse,
move elision or borrowed-proof discount is used. The terminal element layout
comes from a never-called typed selector, not a proof/template allocation.

`claims::fixed` separately charges 16 copies of the complete new admission,
action, report, original Component/child/output headers, all source specs/header
construction and poseidon helper types, CPU and codec envelopes, header/probe
types/results, full cap/public/header arrays, bytes/vector/slice views, codec and
classified failure values, ledger/reservation/quota snapshots, timers and checked
arithmetic. The source-fixed scalar/cursor/array/iteration controls receive
additional fixed word arrays; bounded diagnostics, source-spec forwarding,
copy/drop helpers and Poseidon constants have an additional 64 KiB claim.
Opaque retirement results use never-called function-item layout selectors.

All arithmetic is checked, all device charges are zero, and changed B/C or
codec/schema/helper source requires a fresh census and pinned review. These are
requested-source-storage claims, not allocator overhead, stack/RSS measurements
or a physical worker certificate.

## Evidence scope

Four authored tests cover all-height outer bounds, the exact ceiling/overflow,
changed geometry and additive fixed/decoder/packet/CPU ledger boundaries with
terminal zero. They construct no actual proof or GPU runtime. A performs no
build, formatter, test, planner, auditor, project import or GPU execution.

C's typed header refusals concern syntax and binding only. Core decoder errors
conflate codec, storage and allocation failure and remain unclassified; no
decoder error earns a cryptographic mutation or storage-only rejection count.
The future private in-memory roundtrip provides no disk artifact roundtrip,
complete interior/proof mutation, transaction-context authentication, complete
RingCT workflow, performance, cleanup or production acceptance qualification.
