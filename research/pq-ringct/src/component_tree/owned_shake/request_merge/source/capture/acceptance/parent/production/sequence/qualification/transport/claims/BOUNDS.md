# Private root-transport driver caller census (A048)

This source-only addition belongs beneath B's private, opt-in
`qualification/transport.rs` driver. It changes no selector, module visibility,
producer, security parameter, default, row limit, thread limit or allowance.
The coordinator alone builds and runs it. The underlying A047/B067/C045
transport checkpoint is `959088dec4a2c5bc2c04ab4bb858168fb3a3f3ba`.

`driver_requirement()` preserves every category and byte returned by the
existing `qualification::claims::driver_requirement()`, then adds host-only
PhaseScratch for this concrete transport caller. B's `exercise` admits that
combined request on its original Ledger as its first workload action, before
the environment guard, source arrays, SHAKE fixture, requests or planners.
The published `caller_host_bytes` means that complete baseline-plus-additive
caller. `total_host_bytes` is only the checked sum of this caller and A047's
transport claims. It is not the complete component footprint.

The additive census measures the complete PreissuedRootTransport and retained
report, their Result/Option/borrow layouts, RootTransportMeasurements and its
complete nested header report, and every private plan-report variant using
the maintained method's inferred return type. It independently includes the
complete component/Attempt/source/failure forwarding values and references,
requirements/reservation/ledger/snapshot/error frames, the exact five-element
header-count array and six-element timing array and their IntoIter layouts,
checked arithmetic controls, guard environment results, and stderr/formatting
frames. Eight complete copies are charged, including the census arrays and
helpers. No optimizer, move, inlining, stack-slot reuse or mutually exclusive
branch discount is assumed. The unchanged baseline census separately covers
all input/output fixtures, commitments, five group arrays, source planning,
closure/refusal paths, pending native quota projection and common reporting.

Formatting includes thirty-two complete argument/control and integer/boolean
digit frames and a separately additive 32 KiB fixed helper allowance per
copy. The qualified environment is the exact immutable environment checked by
the coordinator and B/C guard; arbitrary externally mutated environment
values are outside that qualification. The original source/program, native,
compiler, recursive output, acceptance and CPU verifier storage reservations
remain separately owned. This caller census cannot substitute for any of
those claims or A047's decoder/two-full-packet/verifier reservations.

The reviewed concrete order is caller admission, guard, source construction,
PreissuedRootTransport admission, its plan report, Attempt admission, then
capacity projection or the one actual native/recursive run. Both preissue
reservations are therefore live before Attempt can create PendingNativeHashx.
They refer to the same immutable ParentSourceBound, request and Ledger as the
Attempt. Constructor names, Source+Ledger arguments and receipts alone do not
prove this temporal fact; changes to the concrete driver require renewed
review. Every active claim remains additive for quota projection and execution.

In GPU mode the existing component report is checked while the Component is
owned; the same Component then enters its consuming transport action. The
retained transport report holds both A047 originals through the last checked
borrow and formatting of RootTransportMeasurements. The driver then destroys
the retained report, Attempt/transport Options, source, refused closure,
groups and both requests before releasing the caller. Ordinary production,
compiler, transport, report or source failures return after dropping these
local owners in reverse order while that first-declared caller remains live.
Only a fixed `Result<(), &'static str>` crosses the workload boundary. Actual asynchronous
faults, uncertain backend destruction and Rust unwinding remain unqualified.

`terminal_observer_bytes()` is a separate source-only fixed-layout census for
B's Ledger bootstrap and `run`/TerminalObservation harness. It returns a
positive value no larger than 1 MiB, and takes no Ledger, returns no
Requirements and creates no Reservation. It measures concrete fixed
observation/result/snapshot/ledger/allowance/timer/iterator/scalar/formatter
frames, the 4096-byte combined COMPLETE+TERMINAL output ceiling, and bounded
fixed helpers. The original caller has ended before terminal zero is checked.
These bytes grant no worker admission credit and are not an observed memory
peak. They cannot be attributed to released source-storage reservations or a
second Ledger. Full process/reserve enforcement and external terminal audits
cover this explicitly separate harness scope, including its bootstrap census.

The final events contain only fixed copied scalars, bounded static strings and
booleans; they carry `terminal_observer_scope=process-audit-only`,
`released_claims_cover_terminal_observer=false` and
`process_engine_device_audit_complete=false`. Both complete/terminal duration
fields describe the same interval ending after all workload destruction and
before terminal formatting; the external runner bounds the wider interval.
The observer has no packet, proof, key, root measurement, source program,
runtime continuation or dynamic diagnostic to retain. Rust's outer test
harness and the operating system remain in the process guard's scope.

Focused authored tests check preservation of every baseline category, exact
and one-byte-short admission on the original ledger with atomic refusal and
zero balance after release, checked arithmetic overflow, and the independent
bounded/non-admitting observer census. These are arithmetic/ownership tests,
not proof, physical memory, timing or terminal device qualification.

All existing limits remain: 8 GiB managed GPU, 4 GiB context reserve, 32 GiB
worker host, 24 GiB native, 47 GiB process cap, zero swap, and unchanged rows,
threads and cryptographic parameters. Actual root transport, global artifacts,
transaction context, interior/raw proof mutations, complete N3/N4 workflows
and performance remain unqualified until their separate guarded evidence.
