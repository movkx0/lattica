# Private combined HashX qualification driver (B063)

This driver is compiled only into Linux x86_64 release tests with
`owned-native-shake`. Its selectors are ignored by default and stay under
the private B062 sequence module. No dispatcher, external accepted-child input,
raw root/key/proof getter or continuation accessor is added.

All modes use freshly constructed immutable source requests with 16,416 input
bytes and 137 output bytes, genuine SHAKE256 input/output commitments, unchanged
AES64/SHAKE32/24 GiB estimated policy, all ten existing native segments, five
paired source bounds and the full 18-height parent-source envelope. Context is
component-local; every transaction/workflow authority flag remains false. Source
planning programs/templates are not accepted proofs or fresh GPU work.

The driver reservation precedes source arrays, SHAKE fixture work, requests and
planners. It adds eight complete copies of each enclosing owner, all five-group
arrays, Attempt/State/Component and Result/Option/failure layouts, original A
quota projection/results, source closure/refusal/height envelope, output reports,
iterators, stderr/error/environment frames and byte-commitment helpers. Actual
source-planner and produced payload claims remain independently owned. B062's
own caller and every nine-phase output/acceptance/support and bank reservation
are still admitted separately. No constructor or forwarding frame is credited
with inlining, ownership moves or stack-slot reuse.

`cpu_original_hashx_sequence_capacity` requires only
`LATTICA_OWNED_HASHX_SEQUENCE_SOURCE_QUALIFICATION=1`. Its reachable path reserves
the actual pending sequence and every original B claim, then calls A's pure
original quota projection. It checks wrong original request and foreign ledger,
per-category/current totals unchanged after projection, 32 GiB host/8 GiB device
combined quotas and terminal zero balance. It never calls `State::prepare`,
`RegisteredGpuLimits::new`, `OuterSourceEnvelope::inspect`, runtime capture,
Session, native/outer proving or independent numerical verification. The output
explicitly says `physical_backend_fit=false`, `native_dispatch_started=false`
and zero proofs. It does not establish physical or compiler-row feasibility.

`gpu_original_hashx_sequence_preissue` requires the exact coordinator GPU guard
and `LATTICA_OWNED_HASHX_SEQUENCE_QUALIFICATION=1`. It constructs the actual nine
source backends, binds the first and all eight successor plans to A's same
original attempt, and destroys that prepared attempt without proving. Its output
says zero proofs and `actual_proving_fit=false`. Physical source preflight is not
successful proving or performance. Any source refusal is terminal before native
zero, with no fallback or retry.

`gpu_original_hashx_sequence_source_authenticated` uses the same guard and
consumes B062's sole private complete attempt entry. Ten actual native receipt
lines and nine actual outer preprocessing/proof receipt pairs are emitted by
the maintained producers. Provisional phase summaries report exact coverage,
rows/wires/input geometry, compiler time and source CPU verification time.
Setup/proving times remain in those real stage
receipts. The final root must cover units `[0,122)` at level 3. Actual registered
source acceptance and all nine banked destruction/reunification cycles must
succeed before the provisional acceptance-scope diagnostic is emitted. No synthetic accepted owner or
stub backend is used. A failed proof/compiler destroys the whole attempt while
retaining its bounded failure report/caller until final classification.

The narrow `preparation_through_acceptance_ns` timer excludes request/source
work and retained-root destruction. The outer `component_through_destruction_ns`
timer starts before driver/source construction and stops only after `exercise`
has returned and destroyed every root, support, original continuation, compiler,
request/source/group, and driver caller owner. Terminal current totals and every
category must be zero before this marker is printed, on successful or returned
failure paths. The process/engine/GPU teardown audit remains the coordinator's
separate responsibility; an uncertain Session cleanup abort never earns a
successful terminal marker.

Aggregate successful proof/reclamation counts appear only in
`ringct_hashx_sequence_complete`, after successful `exercise` return and the
all-category zero check. This success marker precedes the terminal marker and
shares its final elapsed value. It is absent on any returned failure, destructor
abort, capacity mode or preissue mode. Every earlier leaf/parent/acceptance-scope
diagnostic is explicitly provisional and cannot qualify a completed component.

These are component tests. They intentionally report
`mutation_checks_complete=false`, `artifact_roundtrip_complete=false` and
`complete_ringct_workflow=false`. Matched first-leaf equivalence, injected phase
failure/unwind cases, boundary/context/proof mutations, artifact round trips,
complete transaction/final aggregate closure and seven fresh N3/N4 transactions
remain required. This driver introduces no parent mutation capability merely to
claim those checks. No speedup, production adoption or completed workflow claim
is supported by source review or quota projection alone.

B064 adds four closed ordinary returned-refusal selectors, documented in
`../refusal/BOUNDS.md`. They require an additional exact refusal guard, preserve
all maintained producer/retirement paths, and accept only the requested typed
trip. Their separate refusal-complete marker follows all source/Failure/caller
destruction and terminal zero. They never emit the ordinary component-complete
marker, and their terminal `component_success` remains false even when the
expected-refusal test passed. These source-only probes do not qualify actual
asynchronous faults, unwinding, mutations or full workflows.

B065 adds a separately preclaimed, consuming final-root public recheck, described
in `../root_recheck/BOUNDS.md`. Its root-capacity selector performs only source/
quota projection, and its separate GPU selector verifies the actual original
root, independently probes all 46 public fields using immutable copies, then
verifies the original again. Only numerical RelationRejected counts. Copied
timing reports are consumed under the driver caller and marked provisional; the
final narrow root-public-complete marker follows full exercise destruction and
all-category zero. Global mutation/artifact/full-workflow flags stay false.

All original resource ceilings, rows, threads, security parameters, zero-swap
guard and default Singleton selection remain unchanged. This capsule contains
source only; the coordinator alone may build, test, preflight or execute it.
